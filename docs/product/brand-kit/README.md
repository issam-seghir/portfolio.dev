# Issam Seghir brand kit

| Folder / file                  | What                                                                                                                                           |
| ------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| `issam-seghir-brand-book.pdf`  | The brand book, A4, for reading or sending                                                                                                     |
| `issam-seghir-brand-book.html` | The same page; open it in a browser (needs internet for the fonts)                                                                             |
| `mark-svg/`                    | The doorway mark as vector: default (zellige), inverse (limewash on zellige), dark (light zellige on night), one colour (ink, letters cut out) |
| `mark-png/`                    | The same marks, 1024 px tall, transparent                                                                                                      |
| `lockups/`                     | Mark + name: Latin, Arabic and stacked, transparent PNG, for light and for dark backgrounds                                                    |
| `app-icons/`                   | App icon (SVG and 1024 px), Android and Apple touch icons, favicons (copies of the files in `public/`)                                         |
| `colors.json`                  | The palette, light and dark (the app's source is `src/styles/globals.css`)                                                                     |

Fonts: Reem Kufi (wordmark, headings), Readex Pro (interface, both scripts), JetBrains Mono (code). All are free on Google Fonts.

Rules and reasons: [`../brand.md`](../brand.md). The mark in code: `src/components/ui/logo.tsx`.
